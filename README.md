## 🚀 Quick Start Guide

### Step 1: Get the Code
```bash
# Clone or download this repository
git clone https://github.com/zivapop/TrendyNest-Fashion_store-.git
cd TrendyNest-Fashion_store-
```

### Step 2: Customize Your Content
1. Open `index.html` in your text editor
2. Update store name, description, and branding
3. Add your affiliate links (search for `YOUR_AFFILIATE_LINK`)
4. Replace sample images with your own
5. Customize colors & fonts in `assets/css/style.css`

### Step 3: Enable GitHub Pages
1. Go to **Settings** → **Pages**
2. Select **Main** branch as source
3. Click **Save**
4. Your site will be live at: `https://zivapop.github.io/TrendyNest-Fashion_store-/`

### Step 4: Add Your Affiliate Links
```html
<!-- Replace with your Amazon/Flipkart affiliate links -->
<a href="YOUR_AMAZON_AFFILIATE_LINK" target="_blank">
  Shop Now →
</a>
```

### Step 5: Share & Earn! 💰
- Share your link on social media
- Promote to fashion communities
- Track your earnings in real-time

## 🎓 Customization Guide

### Change Colors & Styling
Edit `assets/css/style.css`:
```css
/* Primary color */
--primary-color: #ff6b6b;

/* Secondary color */
--secondary-color: #ffd93d;

/* Dark background */
--dark-bg: #1a1a1a;
```

### Add More Product Categories
Simply duplicate sections in `index.html` and customize:
```html
<section class="category">
  <h2>Your Category Name</h2>
  <!-- Add product cards here -->
</section>
```

### Update Product Information
```html
<div class="product-card">
  <img src="your-image.jpg" alt="Product">
  <h3>Product Name</h3>
  <p class="price">$XX.XX</p>
  <a href="YOUR_AFFILIATE_LINK" class="btn">Buy Now</a>
</div>
```
